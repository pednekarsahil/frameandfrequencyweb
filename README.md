# FRAME & FREQUENCY

> Every frame. Every frequency.
> A post-production studio for video editing, colour, and audio mixing & mastering.

A bold, brutalist, single-page landing site for **Frame & Frequency** — a Mumbai-based
video editing and audio post studio. Built with a Swiss grid aesthetic, hard edges,
Archivo Black typography, and micro-interactions that make the page feel alive.

---

## ✦ Highlights

- **Typography-first layout** — Archivo Black, Archivo, and Roboto Mono
- **Swiss grid** — 12-column responsive grid with hairline borders
- **Micro-interactions** — hover wobbles, strike-through animations, slide-in buttons
- **Scroll reveals** — IntersectionObserver-driven fade/slide-in on every section
- **Animated counters** — 4K/60 · 96 kHz · 8+ · 300+ count up on scroll
- **Marquee strip** — infinite scrolling services ticker (pauses on hover)
- **Mobile-first responsive** — 1 → 2 → 4 column reflows, sticky nav, mobile menu
- **Accessible** — `prefers-reduced-motion` support, focus-visible outlines, ARIA labels
- **Pure vanilla** — no frameworks, no build step, no dependencies

---

## ✦ Tech Stack

| Layer          | Tech                                      |
|----------------|-------------------------------------------|
| Markup         | HTML5                                     |
| Styling        | Tailwind CSS (CDN) + custom CSS           |
| Fonts          | Google Fonts — Archivo, Archivo Black, Roboto Mono |
| Icons          | Font Awesome 6                            |
| Interactivity  | Vanilla JavaScript (ES6)                  |
| Animation      | CSS keyframes + IntersectionObserver      |

## ✦ Sections

1. **Hero** — Massive typographic statement + live status indicator
2. **Marquee** — Scrolling services strip (editing, colour, mixing, mastering)
3. **Work** — Three index cards for Video Editing / Audio Mixing / Mastering
4. **About** — Editorial spread with stats panel and sector icons
5. **Process** — Four-step workflow (Brief → Edit → Mix → Deliver)
6. **Contact** — Split layout with detailed info + enquiry form
7. **Footer** — Big brand mark + navigation + social
